# Akılcı İlaç Kullanımı

2026-11-28 · 17:30–17:35 · Ortak Program · Kaynak kontrolü 23 Kasım 2026

Programda bu beş dakikalık konuşmanın alt başlığı yayımlanmamış. Bu hazırlığın seçtiği iki örnek AKS sonrası antitrombotik tedavi ve ikincil korunmada ilaç yüküdür. Endikasyon, doz, süre, etkileşim, erişim ve gerçek kullanım birlikte gözden geçirilir. SECURE’da ilaçları tek tablette toplamak ile aspirin kesmek farklı kararlardır.
