## Uygulamada kullanma

Oturum hazırlığı ekranında programdan oturumu seçin. **Aktarım → GitHub’dan indir** düğmesi o oturumun paketini getirir. Moderatörün soru kartları, kaynaklar ve grafikler aynı program kimliğine bağlıdır.
